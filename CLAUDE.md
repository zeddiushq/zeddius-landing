# zeddius-landing

Placeholder page for zeddius.com: a static Next.js export on Firebase Hosting (`firebase deploy --only hosting`, public dir `out`). The earlier landing page and waitlist are in the git history.

Same scaffold as zeddius-web: `app/` routes, `components/` shared components, `components/ui/` generated from the coss registry (`npx shadcn@latest add @coss/<name>`, don't hand-edit), Tailwind v4, Cal Sans and Paper Mono. The theme toggle sits in the top-right corner.
